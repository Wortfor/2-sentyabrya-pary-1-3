
## 1. Название и описание задачи

**Название проекта:** Комплекс задач по объектно-ориентированному программированию (ООП)

**Описание:** Данный проект представляет собой выполнение 9 практических задач по теме "Объектно-ориентированное программирование". Задачи охватывают все три основные концепции ООП: инкапсуляцию, наследование и полиморфизм. Каждая задача находится в отдельной папке и демонстрирует определенный аспект ООП.

**Что делают программы:**
- Задачи 1-2: создание класса `Cat` с атрибутами и методами
- Задача 3: демонстрация инкапсуляции на примере класса `Car`
- Задача 4: демонстрация инкапсуляции на примере класса `Graph`
- Задачи 5-6: наследование на примере классов `Figure`, `Line`, `Rect`, `Ellipse`
- Задача 7: полиморфизм — единый интерфейс для разных типов
- Задача 8: расширение программы новым классом без изменения кода
- Задача 9: мини-графический редактор, объединяющий все три концепции ООП

class Figure:
    def __init__(self, x, y):
        self._x = x          # СКРЫТЫЙ атрибут
        self._y = y          # СКРЫТЫЙ атрибут
    
    def get_coords(self):    # ПУБЛИЧНЫЙ метод

Пример наследования:
class Figure:
    def __init__(self, coords, width, color):
        self.coords = coords
        self.width = width
        self.color = color

class Line(Figure):  # Line наследует Figure
    def __init__(self, coords, width, color, length):
        super().__init__(coords, width, color)  # Вызов конструктора родителя
        self.length = length  # Уникальное свойство

figures = [circle1, square1, circle2, square2, circle3]

# Вычисляем площадь каждой фигуры
total_area = 0
print("Площади фигур:")
for figure in figures:
    area = figure.calculate_area()
    total_area += area
    print(f"  {figure}")

print(f"\nОбщая площадь всех фигур: {total_area:.2f}")

# Демонстрация инкапсуляции (доступ к координатам)
coords = circle1.get_coords()
print(f"\nКоординаты круга: {coords}")
